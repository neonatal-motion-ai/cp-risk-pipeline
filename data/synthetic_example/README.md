# Synthetic example

`scores_synthetic.csv` has the same schema as the restricted per-case score
files of the article, but every value is **synthetic**: it is generated by
`scripts/generate_synthetic_data.py` from parametric distributions (a latent
normal risk variable, Gaussian noise and a logistic squashing), with a fixed
seed. No real data were read, sampled, perturbed or averaged to produce it, and
the case identifiers (`synth_001`, ...) are fictitious.

Regenerate it with:

```bash
python scripts/generate_synthetic_data.py --n 36 --seed 2026
```

Numbers obtained on this file have no clinical meaning; they only demonstrate
that the evaluation code runs end to end.
